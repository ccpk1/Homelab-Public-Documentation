# Homelab Public Documentation Agent Guide

## Scope

This repo contains public-facing homelab documentation.

## Operating Rules

- Keep content safe for public publication. Do not include private infrastructure details, internal hostnames that should stay private, or any secret material.
- Prefer clear, reproducible write-ups over internal shorthand.
- Separate public instructional content from private operator-specific procedures.

## Maintenance Expectations

- When a topic depends on private homelab implementation details, keep those details in `homelab-documentation` and reference only the public-safe part here.
- Keep documentation concise, accurate, and worth publishing.

## Change Standard

- Preserve privacy by default.
- Favor clean explanations and tested steps over exhaustive internal context.
